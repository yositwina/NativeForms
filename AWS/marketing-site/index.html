Native Salesforce forms

Simply create public forms directly from Salesforce

TwinaForms is a native Salesforce app that helps teams create public forms, prefill known data, collect submissions, and write results back to Salesforce without building a custom portal.

What it does

One workspace for the form lifecycle.

TwinaForms gives Salesforce teams a practical path from form design to secure public publishing, without turning every request into a custom portal project.

01

Design in Salesforce

Build forms from a native managed package workspace that follows Salesforce data, users, and setup patterns.

02

Publish to AWS

Publish public HTML forms through the TwinaForms AWS layer while keeping the Salesforce org connected through controlled setup.

03

Prefill known data

Use Salesforce data to reduce typing and guide customers through forms that already know the right context.

04

Write back to Salesforce

Submit records back into standard or custom Salesforce objects using configured submit actions.

Why teams choose it

Simple enough for admins, flexible enough for real processes.

Native app experience

Form designers work from Salesforce tabs with simple UX instead of switching to a separate form-builder account for daily work.

Secret-code workflows

Forms can use a secret-code step for sensitive flows where the respondent should verify access before continuing.

Custom JavaScript support

Advanced teams can add supported JavaScript behavior for specialized form logic while keeping normal forms clean and approachable.

Security and trust

Built on Salesforce and AWS trust.

TwinaForms keeps form design and data access inside Salesforce, and uses AWS for secure published form delivery, storage, and runtime processing.

Salesforce stays the source of truth

Form data is written back to Salesforce, where your team already manages users, permissions, records, and business processes.

AWS protects the public form layer

Published forms run on AWS, one of the world’s most trusted cloud platforms for secure hosting, storage, and application delivery.

Encrypted operational data

Operational logs and service data are encrypted on AWS. Customer-facing access to submitted business data stays in Salesforce.

Designed for responsible access

TwinaForms is designed so business users work in Salesforce, while AWS handles secure delivery and processing behind the scenes.

Plans

Start small, then grow into production.

Every plan keeps the same native TwinaForms foundation. Upgrade when you need more forms, more volume, or advanced Pro behavior.

Included TwinaForms foundation

  • Native Salesforce Form Builder - design forms directly inside Salesforce.
  • Native Prefill - bring Salesforce data into published forms.
  • Native Submit - send form results back into Salesforce.
  • Any standard or custom object - work with the Salesforce data model your org already uses.
  • External user forms - published forms are designed for people outside Salesforce.
  • RTL language support - support right-to-left languages such as Hebrew and Arabic.
